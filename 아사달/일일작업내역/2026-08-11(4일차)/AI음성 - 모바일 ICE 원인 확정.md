# 모바일 ICE 원인 확정

> [!summary] 한 줄 요약
> 모바일 무반응의 근본 원인을 통제 실험으로 확정했다 — **프론트가 ICE 수집을 기다리지 않고 후보 0개짜리 오퍼를 보내는 것**과, 서버가 외부 소스의 비유도(unsolicited) 신규 인바운드 UDP 를 받지 못하는 것의 조합이다. 프로젝트: [[AI음성]]

## 확증 실험 — 같은 망(테더링·통신사)·같은 서버·몇 분 간격

| 실험 | 오퍼 후보 | 결과 |
|---|---|---|
| aiortc, 후보 포함 오퍼 ×8 (포트 33801~56722) | 있음 | **8/8 성공**, ICE 1.5~1.8초 |
| 크로미엄(브라우저 패널), 수집 완료 후 POST | 있음 | **성공**, 응답 8 수신 |
| 크로미엄, 프론트와 동일 — 즉시 POST | **0개** | **실패** — 송신 151 / 응답 0, 사용자 크롬·폰과 동일 시그니처 |
| aiortc, **후보만 제거**한 오퍼 ×3 | **0개** | **3/3 실패** — 성공하던 클라이언트가 뒤집힘 |

변수를 하나씩만 움직였고, **후보 유무만이 성패를 가른다.** 포트·NAT·mDNS·클라이언트 스택 가설은 전부 이 표로 기각됐다.

## 인과 사슬

```
프론트 connect(): setLocalDescription(offer) 직후 offer.sdp 를 즉시 POST
  → 수집 전이라 a=candidate 0줄
  → 서버(비-trickle aiortc)는 원격 후보가 없어 체크를 시작할 대상이 없음
  → 연결 성립은 클라이언트발 체크가 서버에 닿는 것에만 의존
  → 사무실 소스: 신규 인바운드 UDP 가 서버에 도달 → prflx 응답 → 성립 (우연히 동작)
  → 외부 소스(LTE·타 회선): 신규 인바운드 UDP 드롭 → 영원히 checking
```

서버가 후보를 알면(정상 오퍼) **서버가 먼저 쏘고**, 그 아웃바운드가 방화벽 상태(conntrack)를 열어 클라이언트 패킷이 ESTABLISHED 로 통과한다 — aiortc 가 어디서나 됐던 이유다.

## 그동안의 미스터리가 전부 풀린다

| 관측 | 설명 |
|---|---|
| v3(OpenAI 직결)는 모바일에서 됨 | 같은 0-후보 오퍼지만 **OpenAI 는 신규 인바운드 UDP 를 받아준다.** 우리 서버만 못 받는 것 |
| 사무실 데스크톱만 됨 | 사무실 소스는 신뢰 취급되어 신규 인바운드 통과 |
| 외부에서 TCP 9010 차단·9000 개방 | 같은 소스 기반 정책 계열 |
| 과장님 "UDP 제한 없음" | 명시적 UDP 규칙은 없음 — 기본 정책(비유도 신규 인바운드 드롭)이 하는 일이라 서로 모순 아님 |
| 크롬 webrtc-internals: 송신 151 / 응답 0 | 클라이언트발 체크가 서버 앞에서 죽는 그림 그대로 |

## 수정 — 독립적인 두 갈래, 하나만 되어도 해결

**① 프론트 (정석 수정, `Ji-Hwan/frontend` — 전달 사항).** `webrtc_voice_module.js` `connect()` 에서 수집 완료를 기다린 뒤 `pc.localDescription.sdp` 를 보낸다. 비-trickle 서버에는 필수 절차인데 빠져 있었다. 구글 STUN 기준 수집은 보통 0.1~0.5초라 체감 지연 없음. v3 경로도 같은 코드를 타지만 OpenAI 가 관대해서 증상이 없었을 뿐, 이 수정은 v3 에도 무해하고 더 견고해진다.

**② 인프라.** 서버(110.45.147.56)의 임시 포트 대역에 대해 외부 소스의 신규 인바운드 UDP 허용. OpenAI 처럼 동작하게 만드는 것. ①이 되면 필수는 아니지만, 더 험한 NAT(대칭형 매핑 불일치)까지 커버하려면 함께 권장.

장기적으로는 TURN(과제 4번 겸용)이 최종 안전망이다.

## 남긴 교훈

성공 사례가 전부 "후보를 정상 포함하는 클라이언트"였고 실패 사례가 전부 "실제 프론트"였는데, 그 차이를 보기까지 포트·방화벽·NAT·mDNS·기기·브라우저 가설을 차례로 태웠다. **합성 재현 클라이언트가 실제 프론트와 "같은 타이밍"까지 흉내 낸 순간** 원인이 잡혔다 — 재현은 코드가 아니라 행동까지 같아야 한다.
