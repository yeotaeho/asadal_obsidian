## 무슨 작업

게이트를 다시 살리라는 업무를 받아, [[AI음성 - 업링크 투명 탭 재설계]]에서 걷어냈던 소스를 그대로 복구했다. 제거 커밋 `a7e5da9` 이후 해당 6파일을 건드린 커밋이 없어 `git revert` 한 번으로 끝났고, 복원본이 제거 직전 상태와 **바이트 동일**함을 diff 로 확인했다.

복원된 구조.

```
소스 → 지터버퍼(프리버퍼·무음삽입·재타이밍)
     → 게이트(발화길이 1초 + 실발화 600ms + 비율 30%)
     → barge-in(1초 실발화 시 패스스루) → OpenAI
```

세션별 임계값 주입(`ada3c8e`)과 채택/폐기 info 판정 로그(`0d88b9d`)는 제거 이전 커밋이라 복원본에 그대로 포함된다. 투명 탭 전용 테스트는 삭제되고 게이트 시절 테스트가 되살아났다.

## 왜

[[AI음성 - 음성 품질 A B C 실측]]으로 이득 0·비용 실증이 확정돼 제거했던 기능이지만, 이를 다시 복원하라는 업무 지시가 내려왔다. 트레이드오프(발화 소실·감지 지연 +3.5초)를 알고 되돌리는 것이며, 커밋 메시지에도 명시했다.
