# TSE 도입 계획 수립

> [!summary] 한 줄 요약
> 겹침 제거·음질 향상을 위한 TSE(대상 화자 추출) 도입을 브레인스토밍으로 설계하고 Phase A PoC 계획까지 작성했다 — **실행은 보류**(회의 결과 등 후속 판단 대기). 코드 무수정. 프로젝트: [[AI음성]]

## 확정된 설계 (사용자 결정 4건)

| 항목 | 결정 |
|---|---|
| 범위 | 3단계 로드맵 (PoC → 로컬 실시간 → 서버 통합), 단계마다 go/no-go |
| 적용 형태 | 상시 적용 (타인 억제 + 잡음 억제 = 음질 향상) |
| 판정 기준 | 전사 CER — 겹침 **-10%p 개선** 목표, 깨끗한 발화 **+2%p 초과 열화 시 즉시 탈락** |
| 후보 조달 | **공개 모델 + 상용 병행 3군 비교** (O 원본 / P 공개 / C 상용 ElevenLabs Audio Isolation · Krisp 은 B2B 문의 병행) |

핵심 구조: `마이크 → TSE(등록 지문이 리모컨) → 게이트 → OpenAI`. P 군 1순위는 "2화자 분리 후 eres2net 지문으로 사용자 스트림 선택" — 화자 관문 자산 재사용. **전제: 화자 관문 인프라 복원** — 회의에 "화자 관문(1층) + TSE(2층) = 같은 등록 인프라"로 묶어 상정 권장.
