# 오디오 탭 실측과 문제 종합

> [!summary] 한 줄 요약
> 구간별 오디오 탭(WAV 덤프)을 만들어 게이트의 실제 입출력을 귀와 수치로 확정했고, 지터버퍼 2종을 상향했다. 결론: **남은 문제들은 임계값 조정으로 동시 해결이 불가능**하며 프레임 단위 음성 판별(VAD/Krisp)이나 모델 위임으로 가야 한다. 기능: [[음성채팅 v4 복원]]

## 오늘까지 확인된 음성 문제 종합

|---|---|---|---|

| 7 | 짧은 발화·조각의 통째 폐기 | min_utterance 1.2초 — 탭 실측 **후반 54초 방출 0** (모바일 조각화와 결합) | **미해결** — 임계값 트레이드오프 |

## 무슨 작업

**다운링크 폐기 계측**(`7d33f9e`)이 첫 실증을 잡았다 — RAG 검색 6초 뒤 응답 오디오가 몰려온 시점에 `+16프레임(320ms), buffered=24/24`. OpenAI 는 응답을 생성 속도로 몰아 보내므로 응답 시작부 버스트가 구조적으로 발생한다.

**RTP 통계 대조**로 두 번째 실증 — 서버↔OpenAI 지터 13~68ms(정상) vs 서버↔브라우저(모바일) **633~772ms**. 사용자 확인으로 모바일 테스트임이 확정돼, 남은 증상 대부분이 모바일 망 특성 × 고정 버퍼의 충돌임이 드러났다.

**지터버퍼 2종 상향**(`ef530b3`) — 다운링크 480→960, 업링크 320→960 + 업링크 폐기 즉시 로그. 배포 후 업링크가 960에서도 만수위(47/48)를 치는 것까지 관측됐다(모바일 뭉침 피크 1초급).

**구간별 오디오 탭**(`3e9b80d`, `86506ac`, 로그 보강 1건) — `touch /tmp/voice_audio_tap.on` 만으로 켜지는 WAV 덤프. A(브라우저 수신 원음)·B(OpenAI 방출)를 세션마다 남긴다. sudo 불가 환경(운영 계정과 접속 계정 분리, 재시작만 NOPASSWD)에 맞춰 /tmp 플래그 방식으로 설계했다.

## 탭 A/B 실측 판독 (세션 e0538b17, 136초)

방출은 8구간 **10.7초**뿐이고, 그 안의 실발화 밀도가 27~86%로 갈린다.

```
깨끗한 통과   : 5.7~7.1s(82%) · 23.8~25.6s(86%)
잡음 혼합 통과: 34.0~35.5s(44%) · 44.9~47.4s(48%) · 64.8~66.6s(35%)
패스스루 꼬리 : 25.6~25.9s(27%) · 47.5~47.7s
후반 54초     : A 에 조각 수십 개 존재 → B 완전 무음 (전부 폐기)
```

**잡음 혼합 통과가 게이트 설계의 한계를 실증한다** — 1.84초 뭉치에 실발화 0.64초(35%)면 3관문을 전부 합법 통과한다(1.2초↑·0.6초↑·30%↑). 통과가 결정되면 뭉치 안의 잡음 프레임까지 원음 그대로 방출된다. 비율을 50%로 올리면 이런 구간이 차단되지만 그 안의 실발화 44~48%도 같이 죽는다 — **임계값으로는 잡음 차단과 발화 보존을 동시에 못 얻는다.**

## 대안 검토 — 게이트 판정을 어디로 옮길 것인가

| 대안 | 해결되는 것 | 남는 것 |
|---|---|---|
| **A. Realtime 모델 위임** (게이트 제거·투명 탭 복귀) | 지연 +1.5~2.8초 소멸(8-11 투명 탭 실측: **v3 동급**), 조각 폐기 소멸, 잡음-only 는 semantic_vad+far_field 가 무시(8-14 실측: 게이트 소음 차단 이득 0) | 모바일 지터 기인 끊김·유실(네트워크 물리), 사람 말소리 잡음(유튜브), 짧은 소음성 발화의 끼어들기(duration-blind) — 원 요구사항 "2초 이하 무시"의 서버측 보장 포기 |
| **B. Krisp 류 잡음 제거** (프레임 단위, 유료 SDK) | 통과 발화 속 잡음 세척, RMS 판정 정확도 향상 | 지연·조각 폐기(게이트 유지 시 그대로), 모바일 지터, **사람 말소리는 잡음이 아니라 못 가름** |
| **C. Silero VAD 교체** (무료 2MB ONNX) | 음량 대신 "사람 목소리" 판별 — 조용한 발화 보존 + 비음성 잡음 차단 동시 달성 | 모바일 지터, 사람 말소리 잡음 |
| **D. 화자 관문/TSE** (기구현·롤백, 회의 대기) | 사람 말소리 잡음까지 화자 기준으로 차단 | 모바일 지터 |

**모바일 지터(633~772ms)는 어떤 대안으로도 안 사라진다** — 서버 밖 네트워크 물리라 버퍼로 완화만 가능하다.
