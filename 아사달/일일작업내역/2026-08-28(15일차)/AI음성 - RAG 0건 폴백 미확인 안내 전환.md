# RAG 0건 폴백 미확인 안내 전환

> [!summary] 한 줄 요약
> 음성채팅이 검색 0건일 때 LLM 자체 지식으로 단정하던 폴백을 "찾지 못했다" 안내로 교체했다. **196 passed** · Codex 리뷰 지적 없음. 서비스: [[AI음성]]

## 무슨 작업

운영 테스트에서 강남구 챗봇이 학습 데이터에 없는 구청장 이름을 "근거에 따르면 ○○○입니다"라며 단정했다. 원인은 v4 오케스트레이터의 RAG 0건 폴백 두 지점이다. tool answer 를 "AI가 보유한 지식을 바탕으로 직접 답변해 주세요"로 덮어쓰는 곳과, 응답 생성 지시를 "자체 지식으로 간결하게 바로 답변하세요"로 교체하는 곳.

두 지점 모두 "자체 지식으로 답하지 말고, 요청한 정보를 찾지 못했다고 안내하라"로 교체했다. 원래 목적이던 침묵 방지는 "침묵하지 말고 반드시 말로 안내하라" 지시로 유지된다.

## 왜

진단 과정에서 RAG 자체는 정상임을 실증했다. 학습 탭에 "강남구청장은 여태호"를 저장하자 **23초 뒤** 음성이 그 값으로 답했고, 삭제하자 다시 LLM 지식("김현기")으로 단정했다. 즉 문제는 검색이 아니라 0건일 때의 폴백 설계였다.

텍스트 채팅은 같은 DB 를 보고도 이름 없는 안내 카드만 정직하게 반환한다. 음성만 공백을 지어낸 이유가 이 폴백이었다. 데이터에 구청장 이름이 없는 것 자체는 학습 데이터 보강 영역이다.
