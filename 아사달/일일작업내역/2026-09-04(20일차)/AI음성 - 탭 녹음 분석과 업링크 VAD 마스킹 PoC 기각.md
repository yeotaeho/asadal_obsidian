# 탭 녹음 분석과 업링크 VAD 마스킹 PoC 기각

> [!summary] 한 줄 요약
> 구간별 오디오 탭 녹음(게이트 사용 1건·미사용 1건)을 수치로 판독해 게이트의 실제 동작·손실·세션 종료 경위를 확정했고, 대안으로 설계한 Silero VAD 프레임 마스킹은 오프라인 PoC 3회에서 **발화 첫 음절 손실**이 구조적으로 남아 **기각**했다. 코드 변경·커밋 없음. 기능: [[음성채팅 안내문 온오프와 재생 제어]]

## 무슨 작업

### 탭 녹음 판독 (세션 b6c8b7d9, 게이트 사용)

A(브라우저 원음)·B(게이트 방출)·C(OpenAI 수신) 세 파일을 20ms RMS 로 대조했다. B 의 방출 오디오는 A 와 **비트 단위로 동일**하고, A 에서 3관문(1200/600/30%)을 오프라인으로 재현하면 실제 B 방출 15건과 정확히 일치한다. 소리 62.7초 중 **27초 통과, 43초 폐기**.

| 항목 | 실측 |
|---|---|
| 응답 지연 (발화 종료 → AI 응답 시작) | 2.2~12.8초, 중앙값 약 **6초** |
| 40~60ms 차이로 관문 탈락한 발화 | 3건 (voice 1140·1160ms, speech 580ms) |
| 발화 분절 | 4.3초 발화가 1.76초 조각 → 2초 무음 → 1.46초 조각으로 갈림 (패스스루 해제 RMS<400 400ms) |
| B 타임라인 | 벽시계가 아님 — 보류 중 무음 1개 + 통과 시 되감기라 통과 발화만큼 늘어남 |

"발화가 끝났는데 발화 중" 보고의 기제는 패스스루 해제 뒤 뒷부분 재보류다. 마지막 조각이 사용자가 말을 끝낸 뒤 도착하므로 OpenAI 는 그때까지 발화 중으로 본다.

### 게이트 미사용 녹음 (세션 25870326)

바닥 잡음은 거의 없고(중앙값 RMS 2) 잡음은 버스트형이다. OpenAI 응답 14건 중 8건은 실발화 직후, 2~3건이 잡음 유발 의심이나 오디오만으로는 확정 불가다. 확정하려면 dev 로그의 `speech_started` 시각을 A 파일과 대조해야 한다.

### 세션 강제 종료

두 녹음 모두 브라우저 원음이 **말하는 도중** 뚝 끊기고 OpenAI 수신이 약 33초 뒤 닫혔다. 프론트 JS 가 끊는 경로는 전부 release + `pc.close()` 라 서버가 즉시 닫는데, 33초는 aioice 동의 검사(5초 × 6회) 실패 시간이다. 즉 JS 실행 없이 브라우저 측 패킷이 멈춘 것(망 전환·탭 정지 등)이고 프론트에 재접속·ICE 재시작이 없다. 부수 발견은 아래 결정 기록·상세 문서에 반영했다.

- aiortc 는 `disconnected` 상태를 만들지 않아 서버의 30초 유예 경로는 사실상 죽은 코드다.
- 프론트는 OpenAI `error` 이벤트를 종류 불문 통화 종료로 처리한다(`webrtc_voice_module.js:1266`).
- `oniceconnectionstatechange` 핸들러가 빈 함수라 ICE 전이가 콘솔에 남지 않는다.

### 업링크 VAD 마스킹 설계와 PoC

브레인스토밍으로 "붙잡지 않는 프레임 판정" 설계를 확정했다(세션 옵션 병존 · 끼어들기는 OpenAI 위임 · VAD 만 · PoC 선행). 스펙 `docs/superpowers/specs/2026-09-04-voice-uplink-vad-design.md`, 계획 `docs/superpowers/plans/2026-09-04-voice-uplink-vad.md`(레포 미커밋). PoC 는 측정 방법을 세 번 고쳤다.

| 회차 | 정답 | 문제 |
|---|---|---|
| 1차 | RMS>400 = 발화 | 게이트가 통과시킨 15건 중 4건이 유성음 0% 충격음. sherpa `is_speech` 의 래치(`min_speech_duration` 0.25 = 첫 8창 False)도 발견 |
| 2차 | Whisper 단어 타임스탬프 | 긴 무음 위 환각(같은 문장 반복) + 첫 단어 시작 시각이 0.1~0.7초 이름. 다듬어도 손실은 첫 단어에만 |
| 3차 | 발화 뭉치별 원본·마스킹·게이트 전사 대조(CER) | 아래 표. **판정 근거** |

| 변형 | A1 보존/소실/잡음차단 | A2 보존/소실/잡음차단 |
|---|---|---|
| 게이트(오프라인 근사) | 64% / 3 / 71% | 14% / 2 / 85% |
| VAD 0.3, 지연 0 | 36% / 1 / 74% | 14% / 3 / 80% |
| VAD 0.3, 지연 100ms | 71% / 1 / 69% | 43% / 1 / 76% |
| VAD 0.3, 지연 500ms | **79% / 0 / 63%** | **57% / 1 / 72%** |

기준(보존 ≥90% ∧ 소실 0 ∧ 잡음차단 ≥80%)을 넘는 변형이 없다. 손실은 거의 전부 발화 첫 음절("복숭아"→"숭어")이며 Silero 의 시작 감지 지연이 실측 40~600ms 라 인과적 프레임 판정으로는 피할 수 없고, 지연선을 늘리면 잡음 차단이 떨어진다. 사용자 결정으로 **중단**, 브랜치 삭제.

## 왜

사용자 보고 "게이트를 켜면 발화 끝났는데 발화 중·음성 잘림, 끄면 잡음 유입". 음량 하나로는 두 문제를 동시에 풀 값이 없어 음성 확률 판정을 시도했다.

## 검증

- 게이트 오프라인 재현 = 실제 B 방출 15/15 일치. 샘플 동일성 확인(A 6.06초 프레임 = B 7.88초).
- Whisper 호출 약 560회(약 $0.1). 발화 뭉치 A1 14개·A2 7개로 표본이 작다.
- 레포 테스트는 미변경(271 passed 상태 유지).
