# BVC 체험 가이드와 화자 인증 평가 데이터 조사

> [!summary] 한 줄 요약
> ai-coustics Voice Focus(배경 목소리 제거)와 화자 임베딩 모델을 먼저 들이기 위한 준비를 조사했다. ai-coustics 는 **신용카드 없이 30일 체험**이 되고 브라우저 Playground 로 코드 없이 시험할 수 있다. 한국어 실화자 데이터는 **AI Hub 537 화자 인식용 음성(3,000명)** 이 1순위다. 임베딩 모델은 **eres2netv2** 를 1순위로 추천한다. 코드 변경은 없다. 기능: [[음성채팅 v4 복원]]

## 무슨 작업

세 가지를 조사했다. 한국어 실화자 음성을 어디서 구하는지, 화자 임베딩 모델 후보와 추천, ai-coustics 체험판 사용 방법이다.

## 실화자 음성 데이터

| 데이터 | 규모·성격 | 용도 |
|---|---|---|
| **AI Hub 537 화자 인식용 음성** | 3,000명, 약 7,000h. 호출어(짧음)·공통·랜덤 문장·연속발화, 스튜디오·무소음·소음. 화자·성별·연령·기기 메타 | 동성 사칭 쌍 EER — **1순위** |
| AI Hub 542 다화자 음성합성 | 3,495명, 낭독 | 사칭 코호트·점수 정규화 |
| AI Hub 466 감성·발화스타일 | 성우 50명, 7감정 | 감정 강건성 |
| AI Hub 109·107 자유대화 | 2,000명 이상·1,000명 이상 | 대화체·고령 화자 |
| AI Hub 96 명령어 · 538 립리딩 | 스마트폰·태블릿·PC / 소음 6종 | 기기·잡음 보조 |
| Zeroth-Korean | 115명, CC BY 4.0 | 외부 공유용 기준셋 |

AI Hub 는 내국인만 신청할 수 있고, 영리 목적 R&D 와 파생 모델 판매가 된다. 원본 재배포·제3자 제공·국외 반출은 안 된다. "학습용으로만" 조항이 평가 전용에도 해당하는지는 NIA 에 서면 확인이 필요하다. 비상업 전용이라 제외한 것은 VoxBlink2·ClovaCall·ETRI 셋·KMSAV·Pansori 다. VoxCeleb 은 한국인 1명, KsponSpeech 는 화자정보가 없고, Common Voice 한국어는 검증 2.56h 로 작다.

결정적인 셋은 실서비스 WebRTC 경로로 녹음한 사내 셋이다. 성별당 50명 이상, 세션 3회 이상(1주 간격), 본인 휴대폰·PC, 명령·자유대화·감정·작은 목소리·TV 배경을 담는다. 음성 임베딩은 민감정보라 **별도 동의서**가 필요하다.

## 임베딩 모델 추천

| 순위 | 모델(sherpa-onnx) | 크기 | 이유 |
|---|---|---|---|
| 1 | eres2netv2_sv_zh-cn_16k-common | 71.4MB | 논문 제목이 "짧은 발화 화자 검증 성능 향상". 20만 명 학습, CN-Celeb EER 3.81% |
| 2 | campplus_sv_zh_en_16k-common_advanced | 28.3MB | 가장 가볍다. 중국어·영어 학습 |
| 대조 | eres2net_base_200k_sv_zh-cn_16k-common | 39.6MB | 현재와 같은 구조에 데이터만 20만 명. 데이터 효과를 분리 |
| 기준 | eres2net_base_sv_zh-cn_3dspeaker(현재) | 39.6MB | 실통화 본인 중앙값 0.48 |

판정 기준은 한국어 동성 사칭 EER(1.0/1.5/2.0초), 감정 발화 본인 거부율, CPU 다.

## ai-coustics 체험

| 항목 | 내용 |
|---|---|
| 체험 | 30일 무료, 신용카드 불필요, SDK 키 셀프 발급. 업무용 이메일로 가입 |
| Playground | 브라우저에서 Voice Focus·VAD·Tyto 시험 |
| SDK | `aic-sdk` 3.2.0, Python 3.10~3.14, Windows·Linux 휠. 키는 환경변수 `AIC_SDK_LICENSE` |
| 모델 | `quail-vf-2.2-l-16khz`(20MB)·`-s-`(5MB) 주 화자 분리, `vad-vf-2.0-s-16khz` 주 화자 VAD, `vad-ms-2.1` 모든 화자 VAD, `tyto-1.1` 품질 예측 |
| 주의 | **numpy≥2.0.2 요구 — 우리 `requirements.txt` 는 numpy==1.26.4 라 체험은 별도 가상환경.** 키는 온라인 인증·텔레메트리(오디오 전송 없음), 오프라인은 Enterprise(월 $2,000~) |
| 체험 후 | Startup 연 결제 월 $135(월 10만 분) |
