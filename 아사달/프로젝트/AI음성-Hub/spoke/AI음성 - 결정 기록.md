# AI음성 - 결정 기록

> [!summary] 한 줄 요약
> AI음성에서 확정된 설계·운영 결정과 **기각한 대안**의 모음. "왜 이렇게 했더라 / 왜 안 했더라"를 다시 조사하지 않기 위한 노트다. 결정이 뒤집히면 해당 행을 갱신한다. 서비스: [[AI음성]]

## 네트워크·인프라

| 결정 | 이유 | 기각한 대안 | 근거 |
|---|---|---|---|
| **TURN 미도입** | 모바일 무반응의 원인이 프론트 0-후보 오퍼였고, ICE 수집 대기 패치로 해결됨 | TURN 서버 도입 | [[AI음성 - 모바일 ICE 원인 확정]] |
| **외부발 신규 인바운드 UDP 방화벽 허용 안 함** | 프론트 패치로 해결돼 인프라 변경 불필요 | 방화벽 정책 변경 | [[AI음성 - 모바일 정상 동작 확인]] |
| **서버 STUN 기본 제거** (`iceServers=[]`) | 서버는 공인 IP라 srflx == host. STUN 대기가 세션당 5초 지연의 원인 | 기본 STUN 유지 (`ENABLE_SERVER_STUN=on` 으로 복귀 가능) | [[AI음성 - 서버 ICE 수집 5초 지연 제거]] |
| **`gunicorn.conf.py` 의 `worker=` 오타 그대로 두기** | 명령줄 인자가 우선해 무해. 고치다 인자가 빠지면 워커 1개가 되는 위험이 더 큼 | 오타 수정 | [[AI음성 - 원본 브랜치 동등화와 프론트 기록 최신화]] |

## 브랜치·배포

| 결정 | 이유 | 기각한 대안 | 근거 |
|---|---|---|---|
| **main PR 은 원본(main 기준) 브랜치로** — dev 테스트는 `-dev` 사본 | dev 소스가 main 에 유입되면 안 됨 (팀 규칙) | dev 사본으로 main PR | [[음성채팅 v4 복원]] |

## 아키텍처

| **v3·v4 orchestrator 세션별 분기 + v4 패키지 자립(사본)** | v4 를 고치려고 v3 를 건드리는 구조 자체를 제거 | 공용 `server_webrtc` 경유 (복원 초기 상태) | [[AI음성 - v3·v4 orchestrator 분리]] |
| **GA 판정을 접두사 규칙(`gpt-realtime-2*`)으로 통일** | 고정 집합 판정은 2.1 을 폐지된 Legacy 경로로 조용히 떨어뜨림. 프론트와 동일 규칙 | 고정 집합 `{2, 2.0}` 판정 | [[AI음성 - Realtime 모델 2.1 전환과 GA 판정 통일]] |
| **자동 응답 복원 + v4 GA 세션 한정 LangGraph 스킵** | `create_response=False` 차단 방식은 느린 서버 경로(전사 대기+턴 버퍼+Decision LLM)만 남김 — 오리지널 방향 복귀 | 자동 응답 차단 유지 | [[AI음성 - v4 응답 지연 원인 규명과 GA 즉답 경로 복원]] |
| **Tool-Only 휴면 분기 제거** (v2 opt-in 계약째 삭제) | 세팅처 0건 확인 — 죽은 유연성 | 분기 유지 | [[AI음성 - Tool-Only 휴면 분기 제거]] |
| **세션 요청 기본 모델을 GA(`gpt-realtime-2.1`)로** | 기존 기본값 `gpt-realtime-1.5` 는 2026-05-12 폐지된 Beta 평면 스키마 경로 — 프론트가 `model` 을 생략하면 죽은 API 로 세션을 열러 갔다 | v4 만 바꾸고 v3 는 존치 | [[AI음성 - 음성선택 기획서 백엔드 3건]] |
| **voice 를 기획서 10종 `Literal` 로 검증** | 오타가 그대로 OpenAI 로 가면 세션 생성 실패 = 통화 자체가 안 열린다. 라우터에서 422 로 선차단 | 검증 없이 통과시키기 / 별도 음성 목록 API (OpenAPI 스키마가 이미 목록이다) | [[음성 선택과 대기시간 옵션]] |
| **대기시간 미사용은 게이트 없는 `UplinkAudioProxyTrackV4`** | 기반 클래스 직접 사용은 `max_buffer_ms` 가 320 으로 되돌아가 모바일 지터 대응(960) 무효화 + 업링크가 `PROXY-DOWN` 으로 찍혀 방향 구분 소실 | v3 `AudioProxyTrack` 직접 사용 / 게이트 내부 플래그 분기 | [[음성 선택과 대기시간 옵션]] |
