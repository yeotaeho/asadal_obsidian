# 사투리 인식

> [!summary] 한 줄 요약
> 회장님 지시("경상도 사투리를 알아듣게, 기관 보고용 시연에서 그 순간만 되면 된다")로 음성채팅 v4 에 **사투리 지침(세션 지시문)** 과 **VITO STT 사투리 모드(stt_engine=vito)** 를 붙였다. **dev 반영·통화 검증 완료(2026-09-23)**, 앞부분 누락 1건 원인 확인과 main PR 이 남았다. 서비스: [[AI음성]]

## 무엇을 했나

| 구분 | 내용 |
|---|---|
| 자료 | 우리말샘 경상 방언 사전과 AI Hub 경상 말뭉치를 겹쳐, 실제 발화에서 쓰인 **경상 사투리 300쌍** 을 서울시립대 번역지침과 같은 `사투리:표준어` 형식으로 정리. test.han.kr 텍스트학습에 저장 |
| 사투리 지침 | v4 세션을 만들 때 학습 데이터의 `사투리:표준어` 줄을 읽어(5분 캐시) 세션 지시문 끝에 통째로 넣는다. 300쌍 약 2,457자 |
| STT 비교 | 방언 음성 425개로 realtime(운영)·VITO·Qwen3-ASR·CLOVA 를 같은 정답으로 비교 |
| 사투리 모드 | v4 에 `stt_engine=vito` 옵션. 사용자 음성은 VITO 스트리밍이 듣고, OpenAI 에는 침묵을 보내며, VITO 전사를 텍스트로 넣어 realtime 이 음성으로만 답한다 |

## 무엇이 달라졌나

STT 엔진별 문자 오류율(실제 발음 대비, 낮을수록 좋음)이다.

| 엔진 | 전체 425 | 20초 미만 192 | 경상 (전체 / 20초 미만) |
|---|---|---|---|
| realtime (운영) | 24% | 23% | 24% / 31% |
| **VITO** | **18%** | **20%** | **14% / 18%** |
| Qwen3-ASR-1.7B | (239개만) | 23% | – / 25% |
| CLOVA | (qa155) 39% | – | 32% |

**VITO 만 realtime 을 이긴다.** 425개 중 263개 우세, 108개 열세다. 제주는 어느 엔진도 28~29% 로 개선이 없다. Qwen3-ASR 는 realtime 과 동급이고, CLOVA 는 가장 나쁘다.

사투리 모드 로컬 실측(실제 VITO 스트리밍, 실시간 속도 재생)에서 **발화 끝 → 턴 확정은 약 1.0~1.2초** 였다. 모아 보내기 대기 0.8초가 포함된 값이다. 고령 화자의 26초 발화는 말 중간 쉼(2~3초)마다 7조각으로 끊겼다. 그래서 시연은 짧은 질문 한 문장씩 한다.

dev 통화 검증(2026-09-23)에서 경로가 끝까지 동작했다. 세 통화 모두 VITO 전사와 음성 답변이 나왔고, 발화 끝 → 전사는 약 1.2초였다. "혈압약은 시간을 맞추가 … 안 그라면" 처럼 VITO 가 받아 적은 사투리는 모델이 뜻을 알아들었다. 반면 VITO 가 "도라가주씨" 를 "도석간에" 로 받아 적은 문장은 이해하지 못했다. 이것도 병목이 STT 라는 결론과 맞는다. 상세는 [[AI음성 - 사투리 모드 dev 통화 검증]].

## 왜

회장님이 경상도 사투리 말뭉치를 받아 두고, 서울시립대 번역지침처럼 저장해서 실제로 동작하게 해 달라고 했다. 품질보다 "되는 것" 이 우선인 보고용이다.

앞선 실험(2026-09-09~16, 로컬 `사투리` 폴더)에서 사투리 오해의 대부분은 어휘가 아니라 **STT 가 잘못 듣는 것** 이었다. 사전으로 고칠 수 있는 폭은 작다. 그래서 두 방향을 같이 준비했다. 하나는 요청대로 사전을 넣는 것(지침)이고, 다른 하나는 병목인 STT 를 바꾸는 것(VITO)이다.
