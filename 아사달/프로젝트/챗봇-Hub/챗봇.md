# 챗봇

> [!summary] 한 줄 요약
> AI프로 챗봇 본체(대화·모델 선택·RAG)를 담당한다. 현재는 계정이 고를 수 있는 LLM 목록에 신규 모델을 붙이는 작업을 이어가고 있다.

## 서비스 개요

멀티테넌트 학습형 챗봇 플랫폼의 대화 본체다. 백엔드는 `Chatty_Project` 루트의 Chat App(`app.py`)이고, 계정별 `account_setting.yaml` 의 `model_name` 값으로 어떤 LLM 을 쓸지 결정한다.

모델 선택 로직은 `utils/whoami.py` 의 `get_model_by_name()` **단일 지점**에 모여 있다. OpenAI·Anthropic·Google·xAI·Mistral·Clova·Qwen·Kimi·Upstage·EXAONE·Doubao·GLM·Llama 와 RunPod SLLM 까지 전부 이 elif 체인이 분기한다. 별도의 모델 화이트리스트나 토큰 단가표는 레포에 없다.

## 모델 추가 시 알아둘 것

### 접두사 폴백이 이미 깔려 있다

`get_model_by_name()` 에는 provider 별 **접두사 폴백**이 이미 깔려 있다 (`startswith("gemini-")`, `startswith("gpt-")`, `startswith("glm-")`, `startswith("claude-")` 등). 그래서 정식 모델 ID 를 그대로 쓰는 경우 **코드를 고치지 않아도 대개 동작한다**. 명시 분기를 추가하는 실익은 두 가지다.

- 짧은 별칭 제공 (`gemini-3.6`, `glm5.3`)
- 기존 분기와의 스타일 일관성, 그리고 어떤 모델이 공식 지원인지 코드에서 읽히는 것

폴백만으로 안 되는 경우가 두 가지 있고, 이게 진짜 코드를 고쳐야 하는 상황이다.

### temperature 를 거부하는 모델

OpenAI 최신 모델 일부는 `temperature` 가 기본값(1) 외의 값이면 **400** 을 돌려준다. 기본 인자가 `temperature=0` 이라 접두사 폴백으로 떨어지면 **매 호출이 실패한다**. 해당 모델은 `temperature=None` 전용 분기가 반드시 필요하다.

| 모델 | 처리 |
|---|---|
| `gpt-5.3-chat-latest` | `temperature=None` 전용 분기 |
| `gpt-6-astra` | `temperature=None` 전용 분기 |

### 접두사가 겹치는 이름

`startswith()` 로 잡으면 상위 모델이 하위 모델을 가로챌 수 있다. `gpt-6-astra` 를 정확 매칭으로 넣은 것은 Astra Pro 출시 시 `gpt-6-astra-pro` 가 Astra 로 잘못 접히는 것을 막기 위해서다.

### bare 별칭 기본값

바꾸지 않은 것도 있다. **bare 별칭의 기본값**은 옛 버전에 묶여 있다 — `gemini` / `google` → `gemini-2.5-flash`, `glm` / `zhipu` → `glm-5.2`. 승격 여부는 별건이라 손대지 않았다.

### 단가

토큰 단가는 구글 시트에서 관리한다. 레포의 `utils/api_billing.py` 는 이미지 생성(Replicate·DALL·E·Recraft) 전용이라 텍스트 LLM 과는 무관하다.

## 결정 기록

확정된 결정과 **기각한 것**을 남긴다. 같은 조사를 반복하지 않기 위해서다.

| 결정 | 내용 | 이유 |
|---|---|---|
| DeepSeek 정식 ID 교체 **기각** | `deepseek-v4-flash` → `deepseek-flash` 커밋을 만들었다가 revert | 아래 참조 |
| Muse Spark 1.1 도입 **보류** | 코드 미반영 | Meta Model API 가 미국 개발자 전용 public preview. 한국에서는 계정 생성 자체가 불가 |
| `gpt-6-astra` 접두사 매칭 **기각** | `startswith("gpt-6")` 대신 정확 매칭 | Astra Pro 출시 시 오접힘 방지 |

### DeepSeek 을 건드리지 않기로 한 이유

DeepSeek 은 V4.1-Flash 부터 **모델명에서 버전 번호를 뺐다**. 정식 이름은 `deepseek-flash` 이고, `deepseek-v4-flash` 는 "temporarily routed to V4.1 Flash" 로 살아 있는 호환 별칭이다. `deepseek-v4.1-flash` 라는 이름은 **API 가 받지 않는다**.

즉 어느 이름을 보내든 이미 V4.1-Flash 가 응답하고 있다. 버전 핀 고정 수단은 공개 문서에 없다. 정식 ID 로 옮기면 deprecated 경로 의존은 없어지지만, 지금 당장 깨진 것이 없어 되돌렸다. **DeepSeek 이 옛 이름 라우팅을 끊으면 그때 다시 꺼낼 건이다.**

## 작업 시 주의

`utils/` 는 공용 모듈이라 원래 수정 전 확인이 필요한 범위다. 모델 추가 건은 사용자가 `utils/whoami.py` 를 직접 지정해 왔다.

**push 여부는 `git branch -vv` 로 판단하면 안 된다.** `-u` 없이 push 하면 추적 브랜치가 안 잡혀 미push 처럼 보인다. `git ls-remote origin <브랜치>` 로 확인해야 한다. 이걸 놓쳐서 이미 push 된 커밋을 amend 하는 사고가 있었다 ([[챗봇 - Gemini 3.8 Flash·GPT-6 Astra 추가]] 참고).
