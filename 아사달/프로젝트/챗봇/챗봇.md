# 챗봇

> [!summary] 한 줄 요약
> AI프로 챗봇 본체(대화·모델 선택·RAG)를 담당한다. 2026-08-10 계정이 고를 수 있는 LLM 목록에 **Gemini 3.6 Flash** 를 추가했다.

## 서비스 개요

멀티테넌트 학습형 챗봇 플랫폼의 대화 본체다. 백엔드는 `Chatty_Project` 루트의 Chat App(`app.py`)이고, 계정별 `account_setting.yaml` 의 `model_name` 값으로 어떤 LLM 을 쓸지 결정한다.

모델 선택 로직은 `utils/whoami.py` 의 `get_model_by_name()` 한 곳에 모여 있다. OpenAI·Anthropic·Google·xAI·Mistral·Clova·Qwen·Kimi·Upstage·EXAONE·Doubao·GLM·Llama 와 RunPod SLLM 까지 전부 이 elif 체인이 분기한다.

## 무엇을 했나

| 작업 | 상태 |
|---|---|
| Gemini 3.6 Flash 모델 추가 (`gemini-3.6-flash`, 별칭 `gemini-3.6`) | 브랜치 커밋 완료, PR 대기 |

## 무엇이 달라졌나

계정 설정에서 `model_name: gemini-3.6-flash` 또는 짧은 별칭 `gemini-3.6` 을 쓸 수 있다.

정확히 말하면 **긴 이름은 이전에도 통했다**. `get_model_by_name()` 의 `startswith("gemini-")` 폴백이 모든 `gemini-*` 이름을 그대로 `ChatGoogleGenerativeAI` 로 넘기기 때문이다. 이번 커밋이 실제로 추가한 것은 **짧은 별칭 `gemini-3.6`** 과 기존 `gemini-3.5` 분기와의 스타일 일관성이다.

기본값은 건드리지 않았다. `gemini` / `google` 별칭은 여전히 `gemini-2.5-flash` 로 간다.

## 왜

신규 모델 반영 업무를 받았다. 모델 등록 지점이 여러 곳에 흩어져 있는지 확인이 필요했는데, 레포 전역 grep 결과 **`utils/whoami.py` 단일 지점**이었다. `claude-opus-5`, `gpt-5.6-sol` 같은 최신 모델명이 이 파일에만 존재하고, 별도의 화이트리스트나 가격표가 없다.

`token_counter/router.py` 는 `gemini-` 접두사만 검사하므로 모델을 추가할 때 손댈 필요가 없다.
