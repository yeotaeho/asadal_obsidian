# 임베딩·벡터 중복 판정 (v2 1단계)

> [!summary] 한 줄 요약
> 마이그레이션 0003, Voyage 임베딩 어댑터, 전량 백필 4,656건, pg_trgm 을 대체한 벡터 중복·관련 판정을 구현하고 표본 보정으로 임계값 0.96/0.88 을 확정했다. 기능: [[검증 파이프라인 v2]]

## 무슨 작업

브랜치 `feat/verification-v2` 에서 구현서 1단계 Task 1.1~1.8 을 순서대로. 태스크마다 실패 테스트 → 구현 → 통과 → 커밋.

**스키마·모델.** `vector` 확장, `items.embedding`(파이썬 의존성 없이 `CAST(CAST(:v AS text) AS vector)` 로만 쓰는 `Vector` 타입, deferred), `llm_calls`, `feedback.item_id` 유니크(웹훅 upsert), `sources.trust_adjusted`. 피드백 표가 비어 있어 접기 삭제는 없었다.

**임베딩 어댑터.** Voyage 공식 문서로 요청 형식 대조. 1024차원 계약(차원·개수·index 불일치는 `None` 이 아니라 예외), 네트워크·5xx·429 만 재시도, `Retry-After` 존중. `embed_pending` 은 NULL 또는 모델 불일치 행을 잡고, 모델 불일치 행이 남아 있는 동안 파이프라인이 스스로 멈춘다.

**백필.** 처음 128건 배치는 arXiv 초록 구간에서 429 가 이어져 두 번 멈췄다. 무료 등급 제한(RPM 3, TPM 약 1만)이라 **배치 64건·간격 20초·429 기본 대기 20초×시도** 로 바꿔 **4,656건 완료**.

**중복 판정.** 쿼리 A(생존자 중 최댓값)와 B(관련 임계값 이상 전부)를 `text()` SQL 로 분리하고 판정은 순수 함수 `classify`. 버전 토큰 집합이 다르면 중복을 관련로 내린다. 같은 소스 후속 글은 클러스터 상속에는 쓰고 `mention_count` 에서만 뺀다.

**보정.** 7일 창 651건의 쌍 분포를 보고 결정. 0.90~0.95 의 19쌍이 전부 다른 사건(조코딩 다른 영상 0.93, Next.js v16.3.4↔v15.5.25 0.91)이라 중복 **0.96**. 0.80~0.85 의 2,415쌍이 arXiv 두 피드의 주제 이웃이라 관련 **0.88**.

**실데이터 검증.** 수집 35건 적재·임베딩(NULL 0), 72h 창 19건 판정 결과 관련 6·중복 0. canary.17↔19 는 버전 예외로 관련, 조코딩 영상 0.92~0.94 는 관련. 옛 임계값 0.92 였다면 그 영상들이 중복으로 버려졌을 것이다.

## 왜

키워드 관문 v2 의 토대. 임베딩이 중복·mention_count·피드백 사례 검색·이후 증류 분류기까지 전부 받친다. 설계 배경은 [[기술파악 - 검증 파이프라인 v2 설계·구현서]].
