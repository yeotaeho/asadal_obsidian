# 모바일 앱 화면 브랜치 통합

> [!summary] 한 줄 요약
> 흩어져 있던 컨보이 브랜치 5개를 `feat/mobile-app-v0.1` 로 모아 화면 03~11 을 완성했고, Codex 가 찾은 낙관적 쓰기 버그 3건을 고쳐 테스트 **260개 통과**. 기능: [[모바일 앱 v0.1]]

## 무슨 작업

`integration/mobile-app-v0.1-dun` 위에 폴리캣 브랜치 tr-dun.13·14·15·16 을 차례로 병합했다. 충돌은 라우터 import 와 라우터 테스트 오버라이드뿐이었다. 병합 뒤 쓰이지 않는 자리표시 화면을 지웠다.

`flutter analyze` 는 이슈 0건이고 테스트는 **257개 → 260개** 모두 통과한다. 웹 빌드로 피드·찜·설정·관심사·알림 설정·수집 소스·프로필·걸러진 항목·판정 근거를 390폭에서 띄워 디자인과 대조했다.

## 왜

사용자가 design 폴더를 보고 로그인을 뺀 앱 화면을 플러터로 구현해 달라고 했다. 같은 디자인 파일(바이트 단위로 동일)로 만든 구현이 09-24 컨보이 작업에 이미 있어서 새로 짜지 않고 이어받았다.

Codex 리뷰는 겹친 요청에서 실패한 쪽이 스냅샷 전체를 되돌리는 문제를 짚었다.

```
05: 저장 A(실패) · 저장 B(성공) 겹침 → A 실패가 B 까지 화면에서 지움
06: 소스 A 토글(실패) · 소스 B 토글(성공) → B 도 되돌아감
11: 되돌리기 save 성공 → 메모 PATCH 실패 → 서버엔 찜, 목록엔 없음
```
