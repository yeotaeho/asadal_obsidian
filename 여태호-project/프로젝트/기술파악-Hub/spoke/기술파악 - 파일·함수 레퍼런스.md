# 기술파악 - 파일·함수 레퍼런스

> [!summary] 한 줄 요약
> 파일별 공개 심볼, 호출 체인, 그리고 손댈 때 밟기 쉬운 함정들. 서비스: [[기술파악]]

## 파일 지도

| 구분 | 파일 |
|---|---|
| **전용** (한 곳에서만 씀) | `sources/youtube.py`, `api/health.py`, `scripts/run_job.py` |
| **공용** (여러 곳이 의존) | `config.py`, `schemas.py`, `log.py`, `db/models.py`, `db/session.py`, `notify/base.py` |
| **재사용 자산** | `sources/rss.py`(YouTube 재사용), `sources/github_release.release_to_item()`(폴링·웹훅 공유), `pipeline/normalize.py`(ingest), `pipeline/dedupe._similar_within_window()`(find_cluster·mention_count), `notify/discord._call()`(발송·운영 알림 공유), `notify/base` 의 콜백 인코딩·상대 시각(디스코드·텔레그램 공유) |
| **대안 어댑터** (기본 경로 아님) | `notify/telegram.py`, `api/telegram.py` |

## 호출 체인

```
APScheduler
 ├ run_source(id) ─ build_source ─ <Source>.fetch ─ fetch_url
 │                └ [savepoint] store_items ─ is_web_url ─ to_row ─ normalize_url ─ url_hash
 ├ run_pipeline() ─ _llm_calls_today
 │                └ _claim_batch
 │                   └ [savepoint] _process ─ find_cluster            (기준: SCORED·QUEUED·SENT)
 │                                         ├ apply_rules ─ find_keywords / _excluded_domain
 │                                         ├ always_pass → 48h 가드 → 우회   ┐
 │                                         │  그 외      → mention_count      │ 둘 중 하나
 │                                         │            └ score_item          ┘
 │                                         ├ llm.enrich_body
 │                                         └ llm.judge ─ messages.parse
 └ run_notify() ─ _claim_one
                └ decide ─ level_for / in_quiet_hours / push_count_today
                └ DiscordNotifier.send ─ build_payload ─ render ─ escape_md / relative_time
                                       │               └ components ─ _link_button / feedback_callback_data
                                       └ _call ─ 게이트 확인 ─ _extend_gate (429)

FastAPI
 ├ GET  /health           ─ session_scope
 ├ POST /webhook/github   ─ verify_signature(HMAC) ─ release_to_item ─ store_items
 ├ POST /webhook/discord  ─ verify_signature(Ed25519) ─ parse_feedback_callback ─ Feedback
 └ POST /webhook/telegram ─ parse_feedback_callback ─ answer_callback          (대안)
```

## 파일별 심볼

### `app/config.py`

| 심볼 | 설명 |
|---|---|
| `Settings` | `.env` 시크릿. `database_url` 만 필수. `discord_bot_token` · `discord_channel_id` · `discord_public_key` 포함 |
| `SourceConfig` / `ScoringConfig` / `Rules` | `sources.yaml` 항목 / 가중치·`threshold`·`whitelist_max_age_hours` / `rules.yaml` 전체 |
| `get_settings()` / `get_rules()` / `get_source_configs()` | 전부 `lru_cache(1)` |

### `app/db/session.py`

| 심볼 | 설명 |
|---|---|
| `to_asyncpg_url(url)` | libpq 전용 파라미터를 버린다. `ssl` 을 URL 에 넣지 않는다 |
| `requires_tls(url)` / `connect_args(url)` | TLS 면 `ssl=ssl.create_default_context()`, pgbouncer 용 `statement_cache_size=0` |
| `session_scope()` | 성공 시 커밋, 예외 시 롤백. **잡 하나 = 세션 하나** |

### `app/sources/`

| 심볼 | 설명 |
|---|---|
| `base.Source` / `register` / `build_source` | 프로토콜 · 레지스트리 등록 · 타입 → 인스턴스 |
| `base.retryable(exc)` / `fetch_url` | 네트워크·429·5xx 만 재시도, GET + 3회 백오프 |
| `rss.RssSource` | `url`, `category_hint`, `allowed_hosts`(선택). `_host()` 는 URL 전용 |
| `github_release.release_to_item` | 릴리즈 JSON → `NormalizedItem`. 폴링·웹훅 공유 |

### `app/pipeline/`

| 심볼 | 설명 |
|---|---|
| `normalize_url` / `url_hash` / `strip_html` | 정규화·해시·평문화 |
| `ingest.is_web_url(url)` | `http(s)://` 만 True. **적재 전 유일한 URL 스킴 관문** |
| `ingest.store_items(session, source_id, items)` | 스킴 거부(로그) → `ON CONFLICT DO NOTHING` + `RETURNING id` |
| `dedupe.find_cluster` | 72h · similarity > 0.6 · **status ∈ {SCORED, QUEUED, SENT}** |
| `dedupe.mention_count(session, title, exclude_item_id, source_id)` | 유사 제목의 **다른 source_id** distinct 수 + 1. 상태 무관 |
| `rules.apply_rules` → `RuleResult` | 모든 통과 경로가 `matched_keywords` 를 채운다 |
| `scoring.score_item` → `ScoreResult` | 가중합·`breakdown` |
| `llm.enrich_body` / `llm.judge` | 실패 시 `None` / `messages.parse` 1회 |

### `app/jobs/pipeline.py`

| 심볼 | 설명 |
|---|---|
| `_process(session, item, source)` → bool | 관문 ①~⑤. `always_pass_source` 면 48h 이내일 때 점수 우회 |
| `run_pipeline()` | 예산 확인 → 배치 → 항목마다 savepoint. `item_id` 는 진입 전에 뺀다 |

### `app/notify/base.py`

| 심볼 | 설명 |
|---|---|
| `Notifier` | `channel` + `send(item, summary, level, source_name) → message_id` 프로토콜 |
| `RateLimited(RuntimeError)` | 채널이 대기를 요구했다. 항목 실패가 아니라 **배치 중단 신호** |
| `feedback_callback_data` / `parse_feedback_callback` | `fb:useful:123` 왕복. 텔레그램 `callback_data`·디스코드 `custom_id` 공통 |
| `relative_time(published_at, now)` | `12분 전` / `3시간 전` / `2일 전` |

### `app/notify/discord.py`

| 심볼 | 설명 |
|---|---|
| `escape_md(text)` | `*_~`|\[]()#>-` 를 백슬래시 이스케이프. LLM 문자열 전부에 적용 |
| `render(item, summary, source_name, now)` | 굵은 제목 + 요약 + *출처 · 시각* + 태그. 2000자 절단 |
| `_link_button(url)` | `http(s)`·512자 이내일 때만 링크 버튼. 아니면 `None`(버튼 생략) |
| `components(item_id, url)` | 액션 로우 1개: [원문 보기] [👍 유용] [👎 불필요] |
| `build_payload(item, summary, level, source_name)` | 네트워크 없이 검증 가능한 발송 본문. SILENT 면 `flags=4096`, `allowed_mentions.parse=[]` |
| `_retry_after_seconds(response)` | 429 본문 `retry_after`(초). 없으면 1초. **자르지 않는다** |
| `_extend_gate(wait)` | `_blocked_until = max(기존, now+wait)`. 뒤로만 민다 |
| `_call(method, path, payload)` | 매 시도 직전 게이트 확인 → 네트워크·5xx 백오프, 429 게이트+대기, 4xx 즉시 실패. 30초 초과·3회 429 소진은 `RateLimited` |
| `DiscordNotifier.send(...)` | `POST /channels/{id}/messages` → `message_id` |
| `send_ops_alert(text)` | 같은 채널로 ⚠️ 운영 알림 |

### `app/api/discord.py`

| 심볼 | 설명 |
|---|---|
| `verify_signature(public_key_hex, signature_hex, timestamp, body)` | Ed25519. 메시지 = `timestamp + body`. hex 오류·불일치 → False |
| `discord_interaction(...)` | 401 (키 없음·헤더 없음·검증 실패) / PING → PONG / 버튼 → `Feedback` INSERT → ephemeral(flags 64) 답장 |

### `app/notify/policy.py`

`level_for` · `in_quiet_hours` · `push_count_today` · `decide` → `Verdict(level|None, reason)`.

## 손댈 때 규칙·함정

### 트랜잭션

- `session_scope()` 안에서 외부 호출 뒤 커밋하지 마라. `run_notify` 는 항목마다 커밋한다.
- savepoint 롤백은 그 안에서 수정된 객체를 만료시킨다. 롤백 뒤 쓸 값은 진입 전에 빼 둔다 (`MissingGreenlet`).
- `session.commit()` 은 `FOR UPDATE` 락을 푼다.

### 디스코드

- **`_call` 을 우회해서 디스코드에 요청하지 마라.** 게이트·재시도·UA 가 전부 거기 있다. 새 API 호출이 필요하면 `_call` 에 path 만 바꿔 넣는다.
- **`RateLimited` 는 `RuntimeError` 의 하위다.** 발송 잡처럼 "항목 실패" 와 "배치 중단" 을 구분해야 하는 곳은 `except RateLimited` 를 `except Exception` **앞에** 둔다. 순서가 바뀌면 rate limit 이 FAILED 로 박힌다.
- LLM 문자열은 반드시 `escape_md()` 를 거친다. `allowed_mentions` 는 멘션만 막고 서식·링크 마스킹은 못 막는다. `\#`·`\-` 는 디스코드에서 `#`·`-` 로 보인다.
- 링크 버튼 URL 은 디스코드가 `http(s)`·512자 아니면 400 을 낸다. `_link_button` 이 걸러 버튼만 뺀다 — 적재 단계 `is_web_url` 이 근본이고 이건 방어.
- 인터랙션은 **3초** 안에 응답해야 한다. 엔드포인트에서 외부 호출을 하지 마라.
- 서명 검증 메시지는 `timestamp + 원문 바디` 다. FastAPI 가 파싱한 JSON 을 다시 직렬화하면 바이트가 달라져 검증이 깨진다 — `request.body()` 를 그대로 쓴다.
- `DISCORD_PUBLIC_KEY` 가 비어 있으면 엔드포인트가 전부 401 이다. 배포 후 Interactions URL 을 저장할 때 디스코드가 PING 을 보내므로 그 전에 키가 들어가 있어야 한다.
- **429 재시도 테스트에 `no_sleep` 을 쓰지 마라.** sleep 을 즉시 끝내면 게이트(같은 길이)가 만료되기 전에 재시도해 `RateLimited` 가 난다. `retry_after` 를 0.01 로 두고 실제 sleep 을 쓴다. 테스트마다 `_blocked_until` 을 0 으로 되돌리는 autouse 픽스처가 있다.

### 수집기·적재

- 새 소스는 `sources/__init__.py` 에 import 를 추가해야 등록된다.
- `fetch()` 가 예외를 던져야 `last_polled_at` 이 전진하지 않는다.
- 서드파티 미러 피드는 `allowed_hosts` 를 둔다. 설정값은 순수 호스트명이라 `_host()` 로 정규화하면 빈 문자열이 된다.
- 피드 유입 문자열(`author`, `external_id`)은 `text` 컬럼이다.
- `store_items` 가 `http(s)` 아닌 URL 을 조용히 버린다(로그 `ingest.rejected_url`). `decisions` 에는 남지 않는다 — 적재 전이라 `item_id` 가 없다.

### 규칙·점수·중복제거

- `apply_rules` 의 모든 통과 경로는 `matched_keywords` 를 채운다. 비우면 kw=0 으로 화이트리스트가 죽는다.
- `always_pass_source` 는 점수 관문을 건너뛰되 `whitelist_max_age_hours` 를 넘은 항목은 `whitelist_stale`.
- `find_cluster` 의 기준은 SCORED·QUEUED·SENT 뿐. 세 번 뒤집힌 결정 — [[기술파악 - 결정 기록]].
- `mention_count` 는 `cluster_id` 를 세지 않는다. `find_cluster`·`mention_count` 는 Postgres 전용 — 검증은 세션을 열고 `rollback()` 하는 스크립트로.

### 텔레그램 (대안 어댑터)

- `_call` 은 봇 토큰을 URL 에 넣는다. httpx 예외를 그대로 던지면 토큰이 샌다 — 갈아끼우는 코드를 지우지 마라.
- `render()` 는 HTML. LLM 문자열은 `escape()`.

### LLM · 설정

- `messages.parse(...).parsed_output` 은 `Optional` 이라 `assert` 로 좁힌다. 키가 비면 SDK 가 요청 전에 `TypeError`.
- YAML 로더는 `lru_cache`. `sources.yaml` 을 바꾸면 `scripts/run_job.py sync`.

### 검증 스크립트를 쓸 때

- Windows 콘솔은 cp949 — `PYTHONIOENCODING=utf-8`. `tail -N` 은 앞 줄을 잘라 먹는다.
