# 기술파악 - 파일·함수 레퍼런스

> [!summary] 한 줄 요약
> 파일별 공개 심볼, 호출 체인, 그리고 손댈 때 밟기 쉬운 함정들. v2(임베딩·선별·예약·탐색) 기준. 서비스: [[기술파악]]

## 파일 지도

| 구분 | 파일 |
|---|---|
| **전용** (한 곳에서만 씀) | `sources/youtube.py`, `api/health.py`, `scripts/*.py` |
| **공용** (여러 곳이 의존) | `config.py`, `schemas.py`, `log.py`, `db/models.py`, `db/session.py`, `db/budget.py`, `notify/base.py`, `pipeline/embedding.py`, `pipeline/feedback.py` |
| **재사용 자산** | `sources/rss.py`(YouTube), `sources/github_release.release_to_item()`(폴링·웹훅), `pipeline/normalize.py`(ingest), `dedupe.classify()`(순수 함수), `llm.body_for_judge()`·`llm.judge()`·`llm.render_policy()`(파이프라인·탐색·선별 공유), `notify/discord._call()`(발송·운영 알림), `db/feedback.upsert_feedback()`(두 웹훅) |
| **대안 어댑터** | `notify/telegram.py`, `api/telegram.py` |

## 호출 체인

```
APScheduler
 ├ run_source(id) ─ fetch ─ [savepoint] store_items ─ is_web_url ─ to_row
 │                └ embed_pending ─ embedding_text ─ embed (Voyage) ─ _parse_vectors
 ├ run_pipeline() ─ _reembedding_in_progress ─ _claim_batch ─ embed_pending
 │   ├ 1국면 [savepoint] _gate ─ is_stale ─ find_candidates(쿼리 A·B) ─ classify ─ apply_rules
 │   ├ 2국면 _triage ─ _existing_relevance ─ nearest_feedback ─ _triage_once ─ reserve_call("triage") ─ call_triage ─ parse_triage
 │   └ 3국면 [savepoint] _judge ─ score_item ─ body_for_judge ─ reserve_call("judge") ─ nearest_feedback ─ judge
 └ run_notify() ─ _claim_one ─ decide ─ DiscordNotifier.send ─ build_payload ─ _call
                └ _explore ─ in_quiet_hours ─ _explore_sent_today ─ _explore_candidate ─ body_for_judge
                           ─ reserve_call("explore") ─ nearest_feedback ─ judge ─ send(EXPLORE)

FastAPI
 ├ POST /webhook/github   ─ HMAC ─ release_to_item ─ store_items
 ├ POST /webhook/discord  ─ Ed25519 ─ parse_feedback_callback ─ upsert_feedback
 └ POST /webhook/telegram ─ parse_feedback_callback ─ upsert_feedback (대안)

scripts
 ├ backfill_embeddings.py  ─ needs_embedding ─ embed_pending 반복 (배치 간격 20초)

 └ weekly_report.py        ─ 깔때기·정밀도·구간 표, --apply 면 adjust_trust → sources.trust_adjusted
```

## 파일별 심볼

| `PolicyConfig` / `ExcludeConfig` / `DedupeConfig` / `TriageConfig` / `ScoringConfig` / `NotifyConfig` / `Rules` | 전부 `extra="forbid"`. `Rules` 는 `policy`·`exclude`·`dedupe`·`triage`·`scoring`·`notify` |
| `get_settings()` / `get_rules()` / `get_source_configs()` | `lru_cache(1)` |

### `app/db/`

| 심볼 | 설명 |
|---|---|
| `types.Vector(dim)` | `vector(dim)` 컬럼. 쓰기만. `CAST(CAST(:v AS text) AS vector)` 로 asyncpg 코덱 문제를 피한다. 파이썬에서 읽지 않는다 |
| `models.Item.embedding` / `embedding_model` | deferred. 비교는 전부 SQL |
| `models.LlmCall` | `kind`·`batch_id`·`called_at`. 예약 행 |
| `models.Feedback` | `item_id` 유니크 |
| `budget.reserve_call(kind) -> str \| None` | 단일 키 자문 잠금 안에서 오늘 행 수 검사 후 삽입·커밋. 예산은 `BUDGETS`, 상한은 `_caps()` |
| `budget.today_start(tz, now)` | Asia/Seoul 자정 |
| `feedback.upsert_feedback(session, item_id, verdict)` | `ON CONFLICT ON CONSTRAINT uq_feedback_item_id DO UPDATE` |
| `session.session_scope()` | 잡 하나 = 세션 하나 |

### `app/pipeline/`

| 심볼 | 설명 |
|---|---|
| `embedding.embedding_text(title, summary_raw)` | `제목\n본문 300자`. 보강 뒤 재계산 안 함 |
| `embedding.embed(texts) -> list \| None` | 최대 64건. 네트워크·5xx·429 재시도(429 는 20초×시도), 최종 실패 `None`. 차원·개수·index 불일치는 `EmbeddingDimError` |
| `embedding.needs_embedding()` | `embedding IS NULL OR embedding_model IS DISTINCT FROM 현재` |
| `embedding.embed_pending(session, item_ids=None)` | 한 배치 계산해 `update(Item)` 으로 저장. 유일한 벡터 쓰기 경로 |
| `embedding.alert_dim_error(exc)` | 프로세스당 1회 운영 알림 |
| `dedupe.find_candidates(session, item_id, cfg)` | 쿼리 A(생존자 최댓값 1건)·B(관련 전부). 임베딩 NULL 이면 둘 다 빈 결과 |
| `dedupe.classify(...) -> Verdict(kind, cluster_id, mention_count)` | 순수 함수. 버전 토큰 집합 다르면 dup → related. `mention_count` 는 자기 소스 제외 |
| `dedupe.version_tokens(title)` | `v?\d+(\.\d+)+(-.suffix)?` 집합 |
| `rules.apply_rules(rules, *, title, body, url)` | exclude 만. 통과는 `ok` |
| `scoring.score_item(cfg, *, trust, relevance, metrics, mention_count, published_at)` | `rel` 항. 소수 6자리에서 임계값 비교 |
| `scoring.is_stale(published_at, max_age_hours)` | 전역 신선도 가드 |
| `triage.TriageEntry` / `TriageItem` / `TriageBatch` | 입력·출력·구조화 출력 |
| `triage.build_user_content(entries)` | `[idx] 소스 \| 제목\n본문\n    유사 피드백: …` |
| `triage.parse_triage(batch, expected)` | (유효, 항목 실패 idx). 개수·미지 idx 는 `TriageBatchError` |
| `triage.call_triage(rules, entries)` | 시스템 블록에 정책 + `cache_control`. `max_tokens=2048` |
| `feedback.nearest_feedback(session, item_id, *, k, min_sim=0.75)` | 코사인 거리순, 자기 제외 |
| `feedback.format_examples(examples)` | `👍 "제목" · 👎 "제목"` |
| `llm.client()` | `AsyncAnthropic(max_retries=0)` |
| `llm.render_policy(policy)` | 선별·판정 공용 정책 문장 |
| `llm.body_for_judge(item)` | 300자 미만이면 보강. `(본문, 실패 여부)` |
| `llm.judge(rules, *, source, title, body, examples="")` | 구조화 출력 1회 |
| `trust.adjust_trust(base, useful, useless, prior_weight=10)` | 베이즈 평활, [0.2, 1.0] |
| `trust.precision(useful, useless)` / `trust.score_band(score)` | 0 나누기 None / 0.05 구간 |

## 손댈 때 규칙·함정

### 벡터·임베딩

- **벡터를 raw SQL 로 삽입하지 마라.** `update(Item).values(embedding=list)` 하나가 유일한 경로다. `CAST(:v AS vector)` 는 asyncpg 가 vector 로 추론해 코덱이 없어 실패한다.
- `item.embedding` 속성을 파이썬에서 읽지 마라. deferred 라 async 세션에서 `MissingGreenlet`. 존재 여부는 `select(Item.embedding.is_not(None))`.
- `embedding_model` 비교는 `is_distinct_from`. `!=` 는 NULL 을 놓친다.
- 모델을 바꾸면 백필이 끝날 때까지 파이프라인이 스스로 멈춘다. 불일치 행을 NULL 로 되돌리지 않는다.
- 무료 등급은 RPM 3·TPM 약 1만. 배치는 64 이하, 백필은 20초 간격.

### 예약·상한

- **LLM 을 부르는 모든 경로는 `reserve_call` 뒤에 있어야 한다.** 선별 재시도도 새 예약이다. SDK 재시도는 꺼져 있다(`max_retries=0`). 켜면 상한이 깨진다.
- 예약은 독립 세션이다. 배치 트랜잭션 안에서 부르지 말고, 배치가 롤백돼도 예약 행은 남는다는 걸 전제로 한다.
- "오늘" 은 DB `now()` 를 한 번 읽어 범위와 `called_at` 에 같이 쓴다. 시각을 두 번 읽으면 자정에 어긋난다.

### 파이프라인

- 1국면·3국면은 항목별 savepoint, 2국면은 배치 단위다. 항목 실패 카운트는 `session.add` **전에** 센다. 뒤에 세면 autoflush 로 첫 실패에 폐기된다.
- 배치 파싱 실패는 항목 탓이 아니다. 항목 실패로 세는 것은 "응답은 유효한데 특정 idx 가 빠졌거나 범위 밖" 뿐이다.
- 선별 결과는 `decisions` 에 남으므로 판정 예산이 바닥나 NEW 로 남은 항목은 다음 잡에서 호출 없이 재사용된다.
- 탐색 후보 서브쿼리는 `aliased(Decision)` + `correlate(Item)` 이어야 한다. 외부 조인의 `Decision` 과 섞이면 자동 상관으로 FROM 을 잃는다.

### 설정

- `rules.yaml` 은 `extra="forbid"`. 키를 추가하려면 `config.py` 모델에도 넣어야 한다.
- 정책 문장은 `policy.interests`·`not_interested`. 키워드 목록(`focus_stack`)은 힌트일 뿐 관문이 아니다.
- dedupe 임계값(0.96/0.88)은 표본 보정값이다. 바꾸려면 `scripts/calibrate_dedupe.py` 표본을 먼저 본다.

### 테스트

- 통합 테스트는 `TEST_DATABASE_URL`(Neon dev) 이 있을 때만 돈다. 루트 conftest 가 `DATABASE_URL` 을 덮어쓰고, 다르면 건너뛴다 — 운영 DB 보호.
- 테스트마다 이벤트 루프가 새로 생긴다. 통합 conftest 가 매 테스트 뒤 `engine.dispose()`.
- 테스트 헬퍼가 세션을 `async with` 로 감싸 반환하면 닫힌 세션이 온다. `SessionLocal()` 을 열어 돌려주고 호출자가 닫는다.
- 디스코드 429 테스트는 실제 sleep 을 쓴다. Windows 타이머는 최대 15ms 일찍 깨어나므로 `retry_after` 는 0.1 이상.
