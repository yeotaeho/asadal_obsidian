# 기술파악 - 폴더·파일 역할 지도

> [!summary] 한 줄 요약
> 레포의 폴더·파일이 각각 무슨 역할인지와, "이걸 고치려면 어디를 보나" 역인덱스. v2(임베딩·선별·예약·탐색) 기준. 서비스: [[기술파악]]

## 큰 그림

```
sources/  →  적재+임베딩  →  pipeline/ (3국면)  →  notify/ (디스코드 기본, 텔레그램 대안)
    ↑                            ↑                       ↑
    └──────────────────── jobs/ ──────────────────────┘   ← APScheduler 가 호출
                          api/                            ← 웹훅·인터랙션 즉시 경로
                          db/budget.py                    ← 모든 LLM 호출 앞의 예약
                          scripts/                        ← 백필·보정·주간 리포트
```

## 폴더

| 폴더 | 역할 |
|---|---|
| `app/` | 애플리케이션 전부. `main.py`, `config.py`, `schemas.py`, `log.py` |
| `app/db/` | 모델·세션·마이그레이션 + `types.py`(Vector)·`budget.py`(예약)·`feedback.py`(upsert). **스키마의 유일한 출처** |
| `app/sources/` | 수집기 플러그인 |
| `app/pipeline/` | 관문 단계. `normalize`·`rules`·`scoring`·`dedupe.classify`·`trust` 는 DB·HTTP 없는 순수 함수. `embedding`·`triage`·`feedback`·`llm` 은 외부 호출 |
| `app/notify/` | 발송 어댑터와 알림 피로 정책 |
| `app/jobs/` | APScheduler 잡. 트랜잭션 경계를 여는 유일한 계층 (예약 세션 제외) |
| `app/api/` | 헬스체크·GitHub 웹훅·디스코드 인터랙션·텔레그램 콜백 |
| `config/` | `sources.yaml`(소스·신뢰도), `rules.yaml`(정책 문장·exclude·임계값·상한). `extra="forbid"` |
| `tests/` | 단위(respx 모킹) + `integration/`(Neon dev, `TEST_DATABASE_URL`) |
| `scripts/` | `run_job.py`, `backfill_embeddings.py`, `calibrate_dedupe.py`, `weekly_report.py` |
| 루트 문서 | `기획서.md`, `구현도.md`, `검증파이프라인-v2-설계서.md`, `검증파이프라인-v2-구현서.md`, `CLAUDE.md` |
| `.env` | 시크릿. `VOYAGE_API_KEY`, `TEST_DATABASE_URL` 포함. git 무시 |

## 파일

### DB

| 파일 | 역할 |
|---|---|
| `db/models.py` | 테이블 7개. `items.embedding vector(1024)`(deferred)·`embedding_model`, `sources.trust_adjusted`, `feedback` 유니크, `llm_calls` |
| `db/types.py` | `Vector` 타입. text 캐스트로 쓰기만 |
| `db/budget.py` | `reserve_call` — 자문 잠금 예약, 일일 상한 |
| `db/feedback.py` | 피드백 upsert |
| `db/alembic/versions/…0003_embeddings.py` | vector 확장, 임베딩 컬럼, trigram 인덱스 제거, feedback 접기+유니크, llm_calls |

### 파이프라인

| 파일 | 역할 | 외부 |
|---|---|---|
| `pipeline/normalize.py` | URL 정규화·해시 | 없음 |
| `pipeline/ingest.py` | URL 스킴 관문 → `ON CONFLICT DO NOTHING` | DB |
| `pipeline/embedding.py` | Voyage/OpenAI 어댑터, 텍스트 조립, `embed_pending`, 차원 오류 알림 | HTTP·DB |
| `pipeline/dedupe.py` | 쿼리 A/B + 순수 `classify`, 버전 토큰 | DB |
| `pipeline/rules.py` | exclude 만 | 없음 |
| `pipeline/triage.py` | 선별 배치 프롬프트·호출·파싱 | Anthropic |
| `pipeline/scoring.py` | `rel` 가중합, `is_stale` | 없음 |
| `pipeline/feedback.py` | 최근접 피드백 사례 | DB |
| `pipeline/trust.py` | 신뢰도 보정, 정밀도, 점수 구간 | 없음 |
| `pipeline/llm.py` | 보강, 정책 렌더, 판정 | HTTP·Anthropic |

### 잡·발송·API

| 파일 | 역할 |
|---|---|
| `jobs/scheduler.py` | `sources.yaml` → DB 동기화(`trust_adjusted` 는 보존), 잡 등록 |
| `jobs/collect.py` | 폴링 + 적재 + 임베딩 + 실패 카운트·알림 |
| `jobs/pipeline.py` | 3국면 오케스트레이션, 재임베딩 가드 |
| `jobs/notify.py` | 발송 + 탐색 슬롯 |
| `notify/discord.py` | 기본 채널. 🧪 머리말, 429 게이트 |
| `notify/policy.py` | 강도·상한·무음. `EXPLORE` 는 push 집계 제외 |
| `api/discord.py` / `api/telegram.py` | 인터랙션·콜백 → upsert |

## 역인덱스 — 이걸 고치려면 어디를 보나

| 하고 싶은 것 | 볼 곳 |
|---|---|
| 소스 하나 추가 | `sources/<이름>.py` + `sources/__init__.py` + `config/sources.yaml` → `run_job.py sync` |
| **관심사를 바꾼다** | `config/rules.yaml` 의 `policy.interests`·`not_interested` (문장). 키워드 목록이 아니다 |
| 특정 저장소·용어를 더 주목 | `policy.focus_repos`·`focus_stack` (프롬프트 힌트) |
| 홍보·구인 같은 걸 무조건 제외 | `config/rules.yaml` 의 `exclude.keywords`·`domains` |
| 알림이 너무 많다 / 적다 | `scoring.threshold`, `notify.daily_push_cap`, 주간 리포트의 점수 구간 표 |
| 특정 소스가 너무 자주 / 드물게 온다 | `sources.yaml` 의 `trust_score`, 또는 `weekly_report.py --apply` 의 `trust_adjusted` |
| 같은 소식이 두 번 왔다 / 다른 글이 중복으로 묶였다 | `dedupe.dup_threshold`·`related_threshold`. 먼저 `calibrate_dedupe.py` 표본 |
| 오래된 항목이 올라온다 | `scoring.max_age_hours` |
| LLM 비용 | `.env` `LLM_DAILY_CAP`(판정), `rules.yaml` `triage.daily_cap_calls`(선별), `notify.explore_judge_cap` |
| 선별이 후하다 / 짜다 | `pipeline/triage.py` `SYSTEM_PROMPT` 의 눈금, 주간 리포트의 relevance 구간 표 |
| 왜 이 항목이 탈락했나 | `decisions` (`stage` rule/triage/score/llm, `details.reason`·`relevance`·`breakdown`·`triage_reason`) |
| 임베딩 모델 교체 | `.env` `EMBEDDING_MODEL` → `backfill_embeddings.py`. 끝날 때까지 파이프라인이 멈춤 |
| 임베딩이 NULL 로 남는다 | 잡 로그 `embedding.batch_failed`·`http_error`, `sources.last_error` |
| 🧪 실험 카드가 안 온다 | 무음 시간, 오늘 이미 발송, 후보 없음(구간 0.35~0.45·24h), `llm_calls` explore 3회 소진 |
| 피드백이 판정에 반영되는지 | `pipeline/feedback.py` `min_sim`(0.75)·k, 선별 프롬프트의 `유사 피드백:` 줄 |
| 주간 튜닝 | `uv run python scripts/weekly_report.py` (드라이런) → 표를 보고 `rules.yaml` 수정, `--apply` 는 신뢰도만 |
| 통합 테스트 | `TEST_DATABASE_URL=<Neon dev> uv run pytest tests/integration` |
| 테이블 컬럼 추가 | `db/models.py` → `alembic revision --autogenerate` → `upgrade head`. `Vector` 컬럼은 `app.db.types` 를 import |
| 잡을 수동으로 한 번 | `uv run python scripts/run_job.py sync\|collect\|pipeline\|notify` |
