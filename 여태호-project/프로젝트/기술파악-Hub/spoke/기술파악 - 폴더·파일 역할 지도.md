# 기술파악 - 폴더·파일 역할 지도

> [!summary] 한 줄 요약
> 레포의 폴더·파일이 각각 무슨 역할인지와, "이걸 고치려면 어디를 보나" 역인덱스. 서비스: [[기술파악]]

## 큰 그림

세 계층이 전부 플러그인이다. 수집기(`sources/`)는 소스 하나 = 파일 하나, 발송(`notify/`)은 채널 하나 = 파일 하나. 그 사이를 파이프라인 관문(`pipeline/`)이 잇고, 잡(`jobs/`)이 셋을 시간에 맞춰 굴린다.

```
sources/  →  pipeline/  →  notify/ (discord 기본, telegram 대안)
    ↑            ↑            ↑
    └──────── jobs/ ─────────┘   ← APScheduler 가 호출
              api/               ← 웹훅·인터랙션으로 들어오는 즉시 경로
```

## 폴더

| 폴더 | 역할 |
|---|---|
| `app/` | 애플리케이션 전부. 최상위에 엔트리(`main.py`)와 전역 관심사(`config.py`, `schemas.py`, `log.py`) |
| `app/db/` | SQLAlchemy 모델·세션·Alembic 마이그레이션. **DB 스키마의 유일한 출처** |
| `app/sources/` | 수집기 플러그인. `__init__.py` 가 각 모듈을 import 해야 레지스트리에 등록된다 |
| `app/pipeline/` | 관문 단계. `normalize`·`rules`·`scoring` 은 DB·HTTP 없는 순수 함수 |
| `app/notify/` | 발송 어댑터(디스코드·텔레그램)와 알림 피로 정책, 채널 공통 헬퍼 |
| `app/jobs/` | APScheduler 잡. 유일하게 트랜잭션 경계를 여는 계층 |
| `app/api/` | FastAPI 라우터. 헬스체크·GitHub 웹훅·디스코드 인터랙션·텔레그램 콜백 |
| `config/` | 소스 등록·키워드·가중치·발송 정책. **코드에 하드코딩하지 않는 값은 전부 여기** |
| `tests/` | `fixtures/` 에 소스별 실제 응답 샘플, HTTP 는 respx 로 모킹 |
| `scripts/` | 스케줄러 없이 잡을 한 번씩 돌리는 수동 실행기 |
| `.env` (루트) | 시크릿. **git 이 무시한다**. 참조본은 `.env.example` (디스코드 발급 절차 포함) |

## 파일

### 전역

| 파일 | 역할 |
|---|---|
| `app/main.py` | FastAPI 앱 생성, 라우터 4개 등록, 라이프사이클에서 스케줄러 기동·종료 |
| `app/config.py` | `.env` 시크릿(`Settings` — 디스코드 키 3개 포함)과 YAML 로더 |
| `app/schemas.py` | `NormalizedItem`, `LLMVerdict`, 열거형 |
| `app/log.py` | structlog JSON 출력 설정 |

### DB

| 파일 | 역할 |
|---|---|
| `app/db/models.py` | 테이블 6개. 피드 유입 문자열(`author`, `external_id`)은 `text` |
| `app/db/session.py` | async 엔진 + `session_scope()`. TLS 컨텍스트 직접 주입 |
| `app/db/alembic/versions/20260830_0001_initial.py` | 초기 스키마 + `pg_trgm` |
| `app/db/alembic/versions/20260902_0002_widen_feed_strings.py` | `author`·`external_id` → `text` |

### 수집기

| 파일 | 역할 |
|---|---|
| `sources/base.py` | `Source` 프로토콜, 타입 레지스트리, 재시도 HTTP 헬퍼 |
| `sources/rss.py` | 기업 블로그·arXiv 공통. `allowed_hosts` 로 미러의 외부 링크 차단. YouTube 재사용 |
| `sources/github_release.py` | 저장소 릴리즈 병렬 폴링 + 웹훅과 공유하는 변환 함수 |
| `sources/youtube.py` | 채널 RSS URL 만 만들고 `RssSource` 에 위임 |

### 파이프라인

| 파일 | 역할 | DB 접근 |
|---|---|---|
| `pipeline/normalize.py` | URL 정규화·해시, HTML 평문화 | 없음 |
| `pipeline/ingest.py` | **URL 스킴 관문**(`http(s)` 만) → `ON CONFLICT DO NOTHING` | 있음 |
| `pipeline/dedupe.py` | 살아남은 항목 기준 72h 제목 유사도 + 다른 소스 수 | 있음 |
| `pipeline/rules.py` | include/exclude 판정 | 없음 |
| `pipeline/scoring.py` | 가중합·임계값 | 없음 |
| `pipeline/llm.py` | trafilatura 보강 + Claude 구조화 출력 | 없음 |

### 발송·잡·API

| 파일 | 역할 |
|---|---|
| `notify/base.py` | `Notifier` 프로토콜, `RateLimited`, 피드백 콜백 인코딩·상대 시각 (채널 공통) |
| `notify/policy.py` | 강도·하루 상한·무음 시간. **알림 피로 규칙은 전부 여기** |
| `notify/discord.py` | **기본 채널.** 채널 메시지 + 버튼, 마크다운 이스케이프, 429 게이트·재시도, 운영 알림 |
| `notify/telegram.py` | 대안 어댑터. HTML 렌더링, 인라인 키보드, 콜백 응답 |
| `jobs/scheduler.py` | `sources.yaml` → DB 동기화, 잡 등록 |
| `jobs/collect.py` | 소스 폴링 + 적재(savepoint) + 실패 카운트·운영 알림 |
| `jobs/pipeline.py` | 관문 오케스트레이션. LLM 예산 관리 |
| `jobs/notify.py` | 한 건씩 잠그고 발송하고 커밋. `RateLimited` 면 배치 중단 |
| `api/github.py` | HMAC 검증 후 release 즉시 적재 |
| `api/discord.py` | Ed25519 서명 검증 → PING 응답 / 버튼 → 피드백 기록 |
| `api/telegram.py` | 대안. secret token 검증 후 피드백 기록 |

## 역인덱스 — 이걸 고치려면 어디를 보나

| 하고 싶은 것 | 볼 곳 |
|---|---|
| 소스 하나 추가 | `sources/<이름>.py` + `sources/__init__.py` import + `config/sources.yaml` → `scripts/run_job.py sync` |
| 폴링 주기 변경 | `config/sources.yaml` 의 `poll_interval_sec` |
| 관심 키워드 추가 | `config/rules.yaml` 의 `include_keywords` |
| 알림이 너무 많다 / 적다 | `config/rules.yaml` 의 `scoring.threshold`, `notify.daily_push_cap` |
| 화이트리스트 소스(GitHub·YouTube)가 안 온다 | `config/rules.yaml` 의 `scoring.whitelist_max_age_hours`, `decisions` 의 `whitelist_stale` |
| 특정 소스가 LLM 예산을 잠식한다 | `config/sources.yaml` 의 그 소스 `trust_score` |
| 무음 시간 변경 | `config/rules.yaml` 의 `notify.quiet_*` |
| 알림 문구·버튼 변경 | `notify/discord.py` 의 `render()` · `components()` |
| 디스코드 429 가 잦다 / 발송이 멈춘다 | `notify/discord.py` 의 `_blocked_until`·`MAX_RETRY_AFTER`, 잡 로그 `notify.rate_limited` |
| 👍/👎 눌러도 반응이 없다 | 개발자 포털 Interactions Endpoint URL 등록 여부 + `.env` `DISCORD_PUBLIC_KEY` + 잡 로그 `webhook.discord_feedback` |
| 발송 채널을 텔레그램으로 되돌린다 | `jobs/notify.py` 의 기본 `Notifier`, `jobs/collect.py` 의 `send_ops_alert` 임포트 |
| LLM 프롬프트·판단 기준 변경 | `pipeline/llm.py` 의 `SYSTEM_PROMPT` + `config/rules.yaml` 의 `interests` |
| LLM 비용 조절 | `.env` 의 `LLM_DAILY_CAP`, `LLM_MODEL` |
| DB 연결이 안 된다 | `app/db/session.py` 의 `to_asyncpg_url`·`connect_args` |
| 수집이 실패했다 | `sources.fail_count`·`last_error` → 잡 로그 `collect.failed` |
| 항목이 적재조차 안 됐다 | 잡 로그 `ingest.rejected_url` (URL 스킴) 또는 `url_hash` 중복 |
| 왜 이 항목이 탈락했나 | `decisions` (`stage`, `passed`, `details`) |
| 왜 알림이 안 왔나 | `items.status` → `notifications` → 잡 로그 `notify.deferred` / `notify.failed` / `notify.rate_limited` |
| 발송 채널 추가 | `notify/<채널>.py` 에 `Notifier` 구현 + `jobs/notify.py` 주입. 대기 요구는 `RateLimited` 로 |
| 테이블 컬럼 추가 | `db/models.py` → `alembic revision --autogenerate` → `alembic upgrade head` |
| 잡을 수동으로 한 번 돌린다 | `uv run python scripts/run_job.py sync|collect|pipeline|notify` |
