## 서비스 개요

금융 앱의 "신상품 알림" UX 를 개발 정보에 적용한 단일 사용자용 도구다. 여러 소스에서 항목을 모아 정책 관문(중복 → exclude → LLM 선별 → 점수 → LLM 판정)을 거쳐 읽을 가치가 있는 것만 푸시한다. 👍/👎 는 다음 판정에 사례로 들어가고 소스 신뢰도를 보정하며, 하루 1건 경계 항목을 🧪 실험으로 보내 라벨을 모은다. 같은 URL 이 다른 소스에서 다시 오면 metrics·멘션을 합쳐 점수 탈락 항목을 되살린다.

코드는 `C:\project\trend` 한 레포에 전부 있다. 백엔드는 **FastAPI + APScheduler 한 프로세스 + Neon 하나**이고, 프론트엔드는 플러터 앱(`mobile/`)이다. 앱은 `feat/mobile-app-v0.1` 브랜치(워크트리 `C:\project\trend-mobile`)에만 있다. 운영은 Vultr 싱가포르 VM(`149.28.146.228`) 위 Docker Compose (`app` + `caddy`) 이며 Neon 과 같은 리전이다.

기획·설계 원문은 레포 안의 `기획서.md`(v0.1), `구현도.md`(v0.2), `검증파이프라인-v2-설계서.md`, `검증파이프라인-v2-구현서.md`, `v2-다중사용자-1차-구현서.md`(검토만, 축소 적용), `소스확장-1차-설계서.md`, `소스확장-1차-구현서.md`. 앱 디자인은 `design/`(피그마 원본 HTML)과 앱 브랜치의 `docs/design/`·`docs/api/app-api-v1.md` 에 있다. 에이전트용 요약은 `CLAUDE.md`(지도)·`.claude/rules/`(규칙)·`docs/`(지식)에 있다.
