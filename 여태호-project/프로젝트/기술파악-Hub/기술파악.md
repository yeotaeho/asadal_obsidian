# 기술파악

> [!summary] 한 줄 요약
> 새 LLM·라이브러리·MCP·커뮤니티 이슈를 여러 소스에서 감지해 텔레그램으로 밀어주는 개인용 개발 트렌드 알림기. 지금은 0·1단계(골격 + MVP 파이프라인) 구현을 막 끝낸 상태다.

## 서비스 개요

금융 앱의 "신상품 알림" UX 를 개발 정보에 적용한 단일 사용자용 도구다. 여러 소스에서 항목을 모아 규칙 필터 → 점수화 → LLM 판단을 거쳐 읽을 가치가 있는 것만 푸시한다.

코드는 `C:\project\trend` 한 레포에 전부 있다. 프런트엔드는 없고(3단계에 앱 예정), 백엔드는 **FastAPI + APScheduler 한 프로세스 + Neon 하나**로 돌아간다. 배포는 VM 위 Docker Compose (`app` + `caddy`).

기획·설계 원문은 레포 안의 `기획서.md`(v0.1), `구현도.md`(v0.2).
