# 기술파악

> [!summary] 한 줄 요약
> 새 LLM·라이브러리·MCP·커뮤니티 이슈를 여러 소스에서 감지해 **디스코드**로 밀어주는 개인용 개발 트렌드 알림기. 키워드 관문을 **임베딩·LLM 선별·피드백 기반 정책 관문**으로 바꾼 v2 를 4단계 전부 마쳤다(브랜치 `feat/verification-v2`, 머지 대기). 다음은 배포·운영이다.

## 서비스 개요

금융 앱의 "신상품 알림" UX 를 개발 정보에 적용한 단일 사용자용 도구다. 여러 소스에서 항목을 모아 정책 관문(중복 → exclude → LLM 선별 → 점수 → LLM 판정)을 거쳐 읽을 가치가 있는 것만 푸시한다. 👍/👎 는 다음 판정에 사례로 들어가고 소스 신뢰도를 보정하며, 하루 1건 경계 항목을 🧪 실험으로 보내 라벨을 모은다.

코드는 `C:\project\trend` 한 레포에 전부 있다. 프론트엔드는 없고(3단계에 앱 예정), 백엔드는 **FastAPI + APScheduler 한 프로세스 + Neon 하나**로 돌아간다. 배포는 VM 위 Docker Compose (`app` + `caddy`).

기획·설계 원문은 레포 안의 `기획서.md`(v0.1), `구현도.md`(v0.2), `검증파이프라인-v2-설계서.md`, `검증파이프라인-v2-구현서.md`.
