# 리버스 프록시 프리픽스 라우팅과 dev·운영 컨테이너 분리

> [!summary] 한 줄 요약
> 같은 도메인의 프리픽스 분기(`/voice/v1` vs `/voice-dev/v1`)는 "앱 안의 다른 라우터"가 아니라 **다른 업스트림 포트 = 다른 프로세스**로 가는 것이며, host 네트워크에서 dev·운영 컨테이너가 공존하려면 포트가 달라야 한다. AI음성 서비스 분리 과정에서 실측으로 배움. 프로젝트: [[AI음성]]

## 프리픽스 분기의 도착지는 라우터가 아니라 프로세스다

리버스 프록시는 도메인 하나(443)로 받은 요청을 **프리픽스를 보고 업스트림(주소:포트)으로 분기**한 뒤, 프리픽스를 떼고 전달한다. 앱은 프리픽스가 이미 제거된 요청을 받으므로 자기가 `/voice`로 불렸는지 `/voice-dev`로 불렸는지 **알 방법이 없다**.

```
api-aipro.chatbaram.com
 ├─ location /voice/v1      → 127.0.0.1:5252   (운영 컨테이너, main 코드)
 └─ location /voice-dev/v1  → (별도 포트)       (dev 컨테이너, dev 코드)
```

두 프리픽스를 같은 포트로 보낼 수도 있지만, 그러면 두 라우트가 **같은 코드**를 실행해 dev 라우트의 존재 이유(다른 코드 버전 시험)가 사라진다. **다른 코드 버전 = 다른 프로세스 = host 네트워크에선 다른 포트**가 필수.

## 실측 증거 — 503의 판독법

운영 컨테이너(5252) 하나만 살아 있을 때 `/voice/v1`은 **200**, `/voice-dev/v1`은 **503**이었다. 두 프리픽스가 같은 포트를 봤다면 둘 다 200이었을 것. 즉 503은 "dev 업스트림 포트에 응답할 프로세스가 없다"는 뜻이다.

포트를 하드코딩(5252)한 상태로 dev·운영을 같은 서버에 배포하면 한쪽이 bind 실패로 죽는다. 해법은 compose `command`로 `.env`의 `VOICE_PORT`를 주입해 환경별로 포트를 분리하는 것.

## 환경 짝 정합성 — 저장·조회·프론트가 같은 환경을 봐야 한다

기능이 "관리자 저장 → 파일/DB → 서비스 조회 → 발화"처럼 사슬로 이어질 때, **사슬의 모든 고리가 같은 환경(dev vs 운영)을 봐야** 동작한다.

| 고리 | dev | 운영 |
|---|---|---|
| 관리자 저장이 가는 본체 | :9000 | :7000 |
| 본체가 쓰는 저장 경로 (`ACCOUNT_DIR`) | `/NAS/data_dev/account_settings` | `/NAS/data/account_settings` |
| 음성 세션이 가는 라우트 | `/voice-dev/v1` | `/voice/v1` |
| 컨테이너가 마운트하는 경로 | dev 경로 | 운영 경로 |

한 고리라도 어긋나면(예: 저장은 dev 경로, 조회는 운영 경로) 코드가 전부 정상이어도 결과는 "안 됨"으로 보인다. 디버깅할 때 **코드보다 환경 짝부터 대조**하는 게 빠르다.

## 부수로 배운 것들

- **`.env`는 컨테이너 시작 시에만 읽힌다.** `docker restart`는 env_file을 다시 읽지 않는다 — 반영하려면 `docker compose up -d`(재생성).
- **`docker compose up -d`는 이미지 재빌드를 하지 않는다.** 코드 반영은 `--build`, 캐시 의심 시 `build --no-cache`. `COPY . .`까지 CACHED인데 이미지 sha가 같으면 빌드 컨텍스트가 안 바뀐 것.
- **이름 충돌 잔해**: compose 생성 실패로 남은 `Created` 상태 컨테이너는 다음 `up`에서 그대로 기동될 수 있다(구이미지로). `docker ps -a`로 잔해를 확인하고 지워야 한다.
- **`os.path.join(a, "/abs/path")`는 a를 버린다** — DB에 절대경로가 저장돼 있으면 마운트 경로 치환이 무력화되므로, 경로 값이 상대인지 절대인지 먼저 확인.
- SQLite 파일 기반 설정(`chatbot_config.db`)은 서버 파일시스템에 종속 → 컨테이너에서 읽으려면 **읽기 전용 볼륨 마운트**가 필요하고, 환경별 경로가 다르면 `.env`로 분리한다.
